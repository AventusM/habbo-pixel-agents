# S03: Render layer pipeline: formalize room, notes, and dynamic layers

**Milestone:** M003
**Slice:** S03

**Goal:** Generalize the Q12/Q13 render-layer pattern into an explicit WorldLayer pipeline, extracted out of RoomCanvas into a CanvasStage module; module-level mutable renderer state becomes stage-owned.
**Demo:** CanvasStage owns canvas+layers; RoomCanvas shrank by the extracted code; pan/zoom/walk performance not worse (measured render cadence); behavior identical.
