# S02: Implement: RD generation -> pack -> render pipeline

**Milestone:** M001
**Slice:** S02

**Goal:** Generate a character with RetroDiffusion at 48px, pack it into the existing spritesheet+manifest contract (pl_rot_N / pl_idle_N_F / pl_walk_N_F, Texture Packer JSON), and wire it into the renderer - proving the RD pipeline end to end.
**Demo:** A new character spritesheet (e.g. habbo_inspiration_new successor) generated with RetroDiffusion, packed via the updated script, and the avatar walking in the Habbo room at the correct scale.

## Must-Haves

- 1) Pack script consumes RD outputs and emits the renderer contract. 2) One RD character covering 8 directions with walk+idle. 3) Manifest validation passes (key counts, cell size, sheet dims). 4) Avatar visible in the room and walking at the right scale. 5) Generation spend logged.

## Proof Level

- This slice proves: runtime

## Integration Closure

Renderer serves the RD-packed character at runtime; legacy M007/S02 renderer-calibration scope absorbed (48px first; 104px calibration deferred).
