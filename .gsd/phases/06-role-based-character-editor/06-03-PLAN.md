# S03: Outfit persistence + restyle live agents

**Milestone:** M006
**Slice:** S03

**Goal:** Persist customized per-role outfits across page reloads and apply draft edits to live agents without respawning them.
**Demo:** Customize Sisyphus outfit, reload the page, outfit persists; restyle a live walking agent without respawning it.

## Must-Haves

- Customize a role outfit, reload the page, and the outfit persists; editing a draft restyles a live walking agent of that role without respawning it; corrupt/missing storage falls back to ROLE_OUTFIT_PRESETS; vitest + tsc + lint + esbuild green.

## Proof Level

- This slice proves: Unit (vitest) + visual NEEDS-HUMAN: reload-persistence and live-restyle screenshots require a running extension host, unavailable headless — same convention as S01/S02.

## Integration Closure

Spawn path (avatarManager.spawnAvatar/spawnAvatarAt via useRoomAgents) resolves outfits from the persisted outfitStore drafts; a new live-sync hook pushes draft changes onto live AvatarSpec.outfit references so the Nitro draw path (which reads spec.outfit per frame) restyles walking agents in place. No new WS message types; editor overlay untouched.
