## Test Cases — human sign-off (running room)

### 1. Spawn / walk / despawn

1. Open the room (web dashboard or Extension Development Host) with a live/demo feed.
2. Let an agent spawn (walk out of the booth), walk to a target, and despawn.
3. **Expected:** identical timing/paths to `origin/main`; no missing or double avatars;
   speech bubbles and name tags render as before.

### 2. Camera follow

1. Trigger section activity (or `autoFollow` message) and let the 3s auto-follow tick run.
2. **Expected:** camera pans to the most active section exactly as on `origin/main`;
   `jumpToSection` from the bus still centers the target section.

### 3. Kanban filter + note traversal

1. Press `g`/`G` to cycle All → GSD only → Non-GSD; confirm the chip label changes.
2. Click a wall note to expand it, then use ArrowLeft/Right, n/N, p/P, b/B, Escape.
3. **Expected:** filter label cycles via `KANBAN_FILTER_LABELS`; note navigation/back/close
   behaves identically to `origin/main`.

### 4. Editor mode

1. Enter paint/color/furniture modes; paint a tile, recolor a tile, place/rotate furniture.
2. Save the layout and load it back; trigger dev capture in dev mode.
3. **Expected:** placement/rotation/colors/save/load/dev-capture identical to `origin/main`.

### 5. Click + context menu

1. Left-click a wall note, an avatar (including a sitting one), and empty space.
2. Right-click a chair and an empty walkable tile.
3. **Expected:** note expand, avatar select/stand, chair sit/move (with the rAF arrival
   loop) identical to `origin/main`.
