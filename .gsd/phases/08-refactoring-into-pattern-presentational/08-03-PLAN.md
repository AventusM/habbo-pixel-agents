# S03: Complete store wiring: remove mirrored and ref state

**Milestone:** M008
**Slice:** S03

**Goal:** Replace remaining mirrored React state and refs where a store is the source of truth (kanban filter, dev mode, audio readiness) with store subscriptions via hooks; keep per-frame refs that are performance-critical, explicitly documented.
**Demo:** Single source of truth per value; no setX mirrors of store data in the shell; behavior unchanged.

## Must-Haves

- 1) No React state mirrors a src/state store value; store reads go through hooks (useSyncExternalStore/subscribeSelector). 2) Frame-path refs are explicitly kept and documented to preserve perf, and none of them mirrors a store value. 3) npx vitest run + npx tsc --noEmit + npm run lint green; abide/JEV clean on changed files. 4) Behavior parity: same visuals, kanban filter label, dev-mode chrome gate, audio readiness path, spawn/walk/despawn + camera follow unchanged.
