# S03: Vetted rules + calibration

**Milestone:** M011
**Slice:** S03

**Goal:** Introduce the community-vetted example rules and calibrate them.
**Demo:** New rules fire true/false correctly on probe diffs; the calibration report shows decisive/clear medians.

## Must-Haves

- New rules (static-components and no-unstable-dep-identity, or documented equivalent) fire true/false correctly on probe diffs; the calibration report shows decisive/clear medians; `abide rubric validate` passes; `abide calibrate` runs with at most one rewrite round for weak/noisy rules; every rule is mirrored in AGENTS.md; raw calibration evidence is committed under .abide/reports/; rule verdicts are recorded per rule per file.

## Proof Level

- This slice proves: Runtime-demonstrated: a probe diff violating a new rule yields an act-band check verdict, a clean probe diff yields clear, `abide calibrate` medians are decisive/clear per new rule, and raw evidence is committed under .abide/reports/.

## Integration Closure

Touches only the rule surface: .abide/rubric.json, .abide/reports/, AGENTS.md (plus docs/ rule pages). Out of scope: product UI and renderer code, and S04's scripts/hooks/jeve-report.mjs handoff pipeline (S03 only ensures verdicts are recorded per rule per file so the pipeline can consume them).
