# S01: Worktree snapshot reliability

**Milestone:** M011
**Slice:** S01

**Goal:** Diagnose and fix the abide/JEV worktree skip ("git could not snapshot the working tree in time") so that an edit inside a fresh worktree produces a check verdict in .abide/events.jsonl, not a skip.
**Demo:** In a fresh worktree, edit a file and see a check verdict land in .abide/events.jsonl — no skip.

## Must-Haves

- Root cause identified with measured evidence (8s STOP_GIT_TIMEOUT_MS / 5s TURN_START budget vs worktree snapshot cost); fix or documented workaround lands; before/after evidence shows skip -> check in a fresh worktree; no regression in the main checkout; behavior documented.

## Proof Level

- This slice proves: Runtime-demonstrated: a fresh-worktree file edit yields a check verdict (not a skip) recorded in .abide/events.jsonl, with the skip event from before the fix preserved as the baseline.

## Integration Closure

Affects only the abide/JEV enforcement surface (hook config, repo ignore/config tuning, docs, evidence under .abide/reports/); no product UI, renderer, or room-engine code changes.

## Verification

- .abide/events.jsonl gains check verdicts (instead of skips) for worktree edits; before/after evidence committed under .abide/reports/; behavior documented in docs/.
