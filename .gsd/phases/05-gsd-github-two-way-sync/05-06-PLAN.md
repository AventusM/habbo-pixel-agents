# S06: GSD→GitHub hook reactions

**Milestone:** M005
**Slice:** S06

**Goal:** Extend scripts/hooks/gsd-event-hook.mjs with GitHub reactions: on slice skipped/completed events, gh issue comment (or close) the title-prefix-matched issue — honoring the same loop guards as S05 so the two halves never ping-pong.
**Demo:** Skip/complete a GSD slice; the linked GitHub issue receives a bot comment (and closes on completion) within seconds.

## Must-Haves

- 1) complete-slice/skip-slice events produce at most one GitHub reaction each (dedupe by event hash; state survives restarts). 2) Reactions carry the <!-- gsd-sync --> marker and are performed by the authenticated bot account so S05's guard ignores the echo (one hop each way). 3) Safe by default: live gh writes require an explicit --github flag; --dry-run computes and logs intent without calling gh writes. 4) Pure logic covered by vitest; hermetic hook smoke via --event-log/--state fixtures; full suite + tsc green.

## Proof Level

- This slice proves: runtime + tests

## Integration Closure

The hook stays a standalone script (manual / --once); reactions reuse parseTitlePrefix from scripts/gsd-github-sync.mjs so both directions share the title convention; gh calls via execFileSync arg arrays (no shell strings); dedupe state under .gsd/runtime/github-sync/ beside S05's files.
